I build practical AI tools for real problems, mostly Kenyan and East African ones. I focus on systems that are **reliable**: deterministic code does the execution, and AI handles the reasoning.

### 🛠️ How I build
- **Workflows → Agents → Tools:** the AI orchestrates, and tested Python scripts execute. Accuracy holds up even over multi-step tasks.
- **Exact numbers, never guessed:** LLMs choose *what* to compute, and code computes it.
- **Privacy first:** only the minimum data reaches an AI model, and tests enforce it.
